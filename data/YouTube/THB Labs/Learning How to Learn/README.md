# Learning How to Learn

A 27.8-minute Burmese educational narration with one speaker. The reference was
derived from the supplied transcript by removing its Markdown heading, list
markers, and bold markers. Its wording has not been independently verified
against the audio.

```text
audio/learning-how-to-learn.mp3  third-party source; local and ignored by Git
transcripts/learning-how-to-learn.txt  human-readable transcript
references.tsv                  evaluator input keyed by `learning-how-to-learn`
```

The source audio is copyrighted and is not distributed by this repository.
Only `references.tsv` is consumed by `stt eval`; the transcript copy is retained
for human review. The source URL, retrieval date, rights, and transcript-review
provenance are not recorded, so this dataset is diagnostic rather than
publishable benchmark evidence. See the [benchmarking guide](../../../../docs/benchmarking.md).
